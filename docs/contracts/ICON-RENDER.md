# `ICON-RENDER` pointer

- Version: 0.18 (draft)
- Role: consumer, opted in
- Home: `iconography/README.md` in the shared contracts catalog

The site uses 16 px single-colour inline SVGs (20 px on the back-to-top control), its theme's content or
state role, and the shared success and error palette values; it shows no `state.warning` tone. The web
hit-target floor follows the pointer: at least 28 CSS px fine, 44 CSS px coarse - the kit draws
`.btn`, `.seg button`, `.theme-btn` and `.to-top` at 44 px for every pointer. Its button labels provide
the accessible names.
