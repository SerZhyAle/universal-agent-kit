Перевести весь чат на короткие ответы по делуPut the whole chat into brief, signal-only repliesПеревести весь чат на короткі відповіді по суті

/caveman включает краткость только для текущего чата: без воды, без восторгов, без любезностей, а техническая суть остаётся прежней. Вы выбираете степень, lite, full (по умолчанию) или ultra, и режим работает, пока вы его не выключите. Блоки кода, пути к файлам, команды и тексты ошибок остаются точными. Краткость никогда не пропускает проверку: те же проверки идут, сжимается только проза о них./caveman turns on brevity for the current chat only: no filler, no cheerleading, no pleasantries, with the technical substance unchanged. You pick an intensity, lite, full (the default) or ultra, and it stays on until you switch it off. Code blocks, file paths, commands and error strings are left exact. Brevity never skips a check: the same checks run, and only the prose about them shrinks./caveman вмикає стислість лише для поточного чату: без води, без захвату, без люб'язностей, а технічна суть лишається незмінною. Ви обираєте ступінь, lite, full (за замовчуванням) або ultra, і режим працює, доки ви його не вимкнете. Блоки коду, шляхи до файлів, команди й тексти помилок лишаються точними. Стислість ніколи не пропускає перевірку: ті самі перевірки йдуть, стискається лише проза про них.

Когда это нужноWhen to reach for itКоли це потрібно

Ответы агента раздуты, и вам нужна только суть: тот момент, когда хочется сказать «короче» или «хватит воды».The agent's answers are padded and you want only the signal, the moment you would say "be brief" or "stop padding".Відповіді агента роздуті, і вам потрібна лише суть: той момент, коли хочеться сказати «коротше» чи «досить води».

Прежде чем начатьBefore you startПерш ніж почати

Правила безопасности и порядка работы важнее краткости. Предупреждения о безопасности, подтверждения разрушительных или необратимых действий, упорядоченные многошаговые инструкции, где сжатие может ввести в заблуждение, и причина отказа гейта не сжимаются; причина приводится целиком. Просьба о более полном объяснении тоже приостанавливает сжатие.Safety and workflow rules win over brevity. Security warnings, confirmations of destructive or irreversible actions, ordered multi-step instructions where compression can mislead and a refusing gate's reason are not compressed; the reason is quoted whole. Asking for a fuller explanation also pauses the compression.Правила безпеки й порядку роботи важливіші за стислість. Попередження про безпеку, підтвердження руйнівних чи незворотних дій, впорядковані багатокрокові інструкції, де стискання може ввести в оману, і причина відмови гейта не стискаються; причина наводиться повністю. Прохання про повніше пояснення теж призупиняє стискання.

ШагиStepsКроки

  1. Введите /caveman для режима full по умолчанию или добавьте степень: /caveman lite или /caveman ultra. Строка вызова: /caveman [optional: lite|full|ultra].Type /caveman for the default full mode, or add an intensity: /caveman lite or /caveman ultra. The usage line is /caveman [optional: lite|full|ultra].Введіть /caveman для режиму full за замовчуванням або додайте ступінь: /caveman lite чи /caveman ultra. Рядок виклику: /caveman [optional: lite|full|ultra].
  2. Агент применяет выбранную степень. lite: короткие законченные предложения, без воды. full: допустимы обрывки фраз, артикли, вода и любезности убираются. ultra: максимальное безопасное сжатие, сокращается только проза.The agent applies the chosen intensity. lite: short full sentences, no filler. full: fragments allowed, articles, filler and pleasantries dropped. ultra: maximum safe compression, abbreviating prose only.Агент застосовує обрану ступінь. lite: короткі закінчені речення, без води. full: припустимі уривки фраз, артиклі, вода й люб'язності прибираються. ultra: максимальне безпечне стискання, скорочується лише проза.
  3. Техническая суть остаётся точной. Ответы строятся по образцу [thing] [action] [reason]. [next step]., а блоки кода, пути к файлам, команды, символы, имена функций, классов и API и тексты ошибок остаются без изменений. ultra их никогда не сокращает.Technical substance stays exact. Replies prefer the pattern [thing] [action] [reason]. [next step]., and code blocks, file paths, commands, symbols, function, class and API names and error strings are kept unchanged. ultra never abbreviates them.Технічна суть лишається точною. Відповіді будуються за зразком [thing] [action] [reason]. [next step]., а блоки коду, шляхи до файлів, команди, символи, імена функцій, класів і API та тексти помилок лишаються без змін. ultra їх ніколи не скорочує.
  4. Обязательная маршрутизация к другим навыкам сохраняется: семейство /spec, /ui-clarify, /git и /prove продолжают действовать.Mandatory routing to the other skills is preserved: the /spec family, /ui-clarify, /git and /prove still apply.Обов'язкова маршрутизація до інших навичок зберігається: родина /spec, /ui-clarify, /git і /prove продовжують діяти.
  5. Ни проверка, ни гейт, ни подтверждение не пропускаются ради экономии слов. Идут те же проверки, что и в обычном чате; сжимается только проза о них.No check, gate or confirmation is skipped to save words. The same checks run as in a normal chat; only the prose about them shrinks.Жодна перевірка, жоден гейт і жодне підтвердження не пропускаються заради економії слів. Ідуть ті самі перевірки, що й у звичайному чаті; стискається лише проза про них.
  6. Когда важна ясность, агент приостанавливает сжатие для этого ответа: при предупреждениях о безопасности, подтверждениях разрушительных или необратимых действий, упорядоченных многошаговых инструкциях, где сжатие может ввести в заблуждение, при причине отказа гейта или проверки и всякий раз, когда вы просите объяснить подробнее. Причина приводится целиком: refused: the ticket has an unanswered open question её сохраняет, голое refused теряет.When clarity matters, the agent suspends compression for that answer: security warnings, destructive or irreversible confirmations, ordered multi-step instructions where compression can mislead, a refusing gate's or check's reason, and any time you ask for a fuller explanation. The reason is quoted whole: refused: the ticket has an unanswered open question keeps it, a bare refused drops it.Коли важлива ясність, агент призупиняє стискання для цієї відповіді: за попереджень про безпеку, підтверджень руйнівних чи незворотних дій, впорядкованих багатокрокових інструкцій, де стискання може ввести в оману, за причини відмови гейта чи перевірки і щоразу, коли ви просите пояснити докладніше. Причина наводиться повністю: refused: the ticket has an unanswered open question її зберігає, голе refused втрачає.
  7. Режим держится, пока вы не введёте stop caveman или normal mode. Он включается только по вашему желанию и действует лишь в текущем чате.The mode holds until you type stop caveman or normal mode. It is opt-in and applies to the current chat only.Режим тримається, доки ви не введете stop caveman чи normal mode. Він вмикається лише за вашим бажанням і діє тільки в поточному чаті.

Ответы без воды, любезностей и похвал, построенные примерно так: Build fails. Missing env var. Set it, rerun., при этом каждая команда, путь и текст ошибки остаются нетронутыми. Ответы, важные для безопасности, и причина отказа гейта по-прежнему приходят полностью.Replies without filler, pleasantries or praise, shaped like Build fails. Missing env var. Set it, rerun., with every command, path and error string intact. Safety-critical answers and a refusing gate's reason still come in full.Відповіді без води, люб'язностей і похвал, збудовані приблизно так: Build fails. Missing env var. Set it, rerun., при цьому кожна команда, шлях і текст помилки лишаються недоторканими. Відповіді, важливі для безпеки, і причина відмови гейта, як і раніше, приходять повністю.

СоветыTipsПоради

  • Ответы остаются на языке вашего чата, а код, документы, журналы и коммиты пишутся на языке, который ваш проект задал в <ARTIFACT_LANGUAGE> - плейсхолдере файла правил.Replies stay in your chat language, while code, docs, logs and commits are written in the language your project set as <ARTIFACT_LANGUAGE>, a placeholder of the rules file.Відповіді лишаються мовою вашого чату, а код, документи, журнали й коміти пишуться мовою, яку ваш проєкт задав у <ARTIFACT_LANGUAGE> - плейсхолдері файлу правил.
  • В заголовке навыка стоит disable-model-invocation: true, поэтому в Claude Code агент не включает режим краткости сам: его включает только ваш /caveman.The skill's header sets disable-model-invocation: true, so in Claude Code the agent does not switch brevity mode on by itself: only your /caveman does.У заголовку навички стоїть disable-model-invocation: true, тому в Claude Code агент не вмикає режим стислості сам: його вмикає лише ваш /caveman.
  • /caveman меняет манеру всего чата. Для одного сообщения коммита используйте /caveman-commit, для одного ревью - /caveman-review. Это отдельные команды, каждая работает сама по себе./caveman changes how the whole chat talks. For one commit message use /caveman-commit, for one review use /caveman-review. They are separate commands, each used on its own./caveman змінює манеру всього чату. Для одного повідомлення коміту використовуйте /caveman-commit, для одного рев'ю - /caveman-review. Це окремі команди, кожна працює сама по собі.
