What's newЧто новогоЩо нового

What changed in each build of the kit, newest first. A build is named by its date, the same date as the line Kit updated on the landing page and the file VERSION in the zip.Что изменилось в каждой сборке kit, сначала новые. Сборка называется по дате - той же, что в строке Kit обновлён на главной странице и в файле VERSION в zip.Що змінилося в кожній збірці kit, спочатку нові. Збірка називається за датою - тією самою, що в рядку Kit оновлено на головній сторінці та у файлі VERSION у zip.

Build ofСборка отЗбірка від 2026-11-16

  • A recorded check says where it was observed - the machine or device with its software version - and a pass on a simulator or an emulator is named as the lower rung it is, never presented as a device pass (docs/VALIDATION.md); the /prove header's environment line carries the where-observed statement as advice.Записанная проверка теперь называет, где её наблюдали - машину или устройство с версией ПО, - а проход на симуляторе или эмуляторе признаётся той более низкой ступенью, которой он является, и никогда не выдаётся за проход на устройстве (docs/VALIDATION.md); строка environment в заголовке /prove несёт это как совет.Записана перевірка тепер називає, де її спостерігали - машину чи пристрій із версією ПЗ, - а проход на симуляторі чи емуляторі визнається тим нижчим щаблем, яким він є, і ніколи не вдається за проходження на пристрої (docs/VALIDATION.md); рядок environment у заголовку /prove несе це як пораду.

Build ofСборка отЗбірка від 2026-11-10

  • The 5-second rule for checks between releases is stated once, in docs/VALIDATION.md; every skill, role agent and the phase template names its tier at the step that picks a check.Правило 5 секунд для проверок между релизами записано в одном месте, в docs/VALIDATION.md; каждый навык, каждая роль и шаблон фазы называют свой уровень на шаге, где выбирается проверка.Правило 5 секунд для перевірок між релізами записано в одному місці, у docs/VALIDATION.md; кожна навичка, кожна роль і шаблон фази називають свій рівень на кроці, де обирається перевірка.
  • AGENTS.md is back under 12,000 characters, and the filled example in examples/ matches the template again.AGENTS.md снова короче 12 000 символов, а заполненный пример в examples/ снова совпадает с шаблоном.AGENTS.md знову коротший за 12 000 символів, а заповнений приклад у examples/ знову збігається з шаблоном.
  • The window-help convention ships with the /ui-clarify skill: a help button and a help page or layer for each window of an application.Соглашение о справке для окон входит в навык /ui-clarify: кнопка справки и страница или слой справки для каждого окна приложения.Угода про довідку для вікон входить до навички /ui-clarify: кнопка довідки та сторінка або шар довідки для кожного вікна застосунку.

Build ofСборка отЗбірка від 2026-10-09

  • Skills replace commands: 19 skills in the open Agent Skills format under .claude/skills/<name>/SKILL.md. the old /verify is now /prove and the old /review is now /critique, so neither shadows a built-in command; the new /surfaces skill checks the surfaces that ship together.Навыки заменили команды: 19 навыков в открытом формате Agent Skills в .claude/skills/<name>/SKILL.md. прежний /verify теперь /prove, а прежний /review теперь /critique, чтобы ни один не перекрывал встроенную команду; новый навык /surfaces проверяет поверхности, которые выходят вместе.Навички замінили команди: 19 навичок у відкритому форматі Agent Skills у .claude/skills/<name>/SKILL.md. колишній /verify тепер /prove, а колишній /review тепер /critique, щоб жодна не перекривала вбудовану команду; нова навичка /surfaces перевіряє поверхні, що виходять разом.
  • AGENTS.md is the one rules file, and CLAUDE.md imports it and the memory index. The permission template no longer allows every git command: push and rebase ask, force push, hard reset and clean are denied.AGENTS.md - единственный файл правил, а CLAUDE.md подключает его и индекс памяти. Шаблон разрешений больше не разрешает любую команду git: push и rebase спрашивают, force push, hard reset и clean запрещены.AGENTS.md - єдиний файл правил, а CLAUDE.md підключає його та індекс пам'яті. Шаблон дозволів більше не дозволяє будь-яку команду git: push і rebase питають, force push, hard reset і clean заборонені.
  • The kit carries VERSION, its build date; the merge prompt records the adopted date, runs a self-check and has an upgrade mode.В kit есть VERSION - дата сборки; промпт слияния записывает принятую дату, выполняет самопроверку и умеет обновлять.У kit є VERSION - дата збірки; промпт злиття записує прийняту дату, виконує самоперевірку й уміє оновлювати.
