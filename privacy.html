Ничего. Страницы никуда не отправляют данные. Единственный собственный запрос страницы - за индексом поиска, к этому же сайту, и только когда вы открываете поиск. ХостингHostingХостинг

Файлы отдаёт GitHub Pages. Как и любой веб-хостинг, GitHub получает ваш запрос, включая IP-адрес, и ведёт собственные записи по заявлению GitHub о конфиденциальности. Автор не ведёт поверх этого ни собственной аналитики, ни собственных логов.GitHub Pages serves the files. Like any web host, GitHub receives your request, including your IP address, and keeps its own records under GitHub's privacy statement. The author runs no analytics or logging of their own on top of it.Файли віддає GitHub Pages. Як і будь-який вебхостинг, GitHub отримує ваш запит, зокрема IP-адресу, і веде власні записи за заявою GitHub про конфіденційність. Автор не веде поверх цього ні власної аналітики, ні власних логів.

Скачиваемый файлThe downloadФайл для завантаження

В universal-agent-kit.zip лежат обычные Markdown-файлы, один JSON-шаблон настроек и один текстовый файл. Ничто в нём не устанавливается и не запускается само, телеметрии в нём нет. Что ваш агент делает с отданными ему файлами, определяет вендор этого агента, а не этот сайт.universal-agent-kit.zip holds plain Markdown files, one JSON settings template and one text file. Nothing in it installs or runs by itself, and it has no telemetry. What your own agent does with the files you give it is governed by that agent's vendor, not by this site.У universal-agent-kit.zip лежать звичайні Markdown-файли, один JSON-шаблон налаштувань і один текстовий файл. Ніщо в ньому не встановлюється й не запускається саме, телеметрії в ньому немає. Що ваш агент робить із файлами, які йому дали, визначає вендор цього агента, а не цей сайт.
